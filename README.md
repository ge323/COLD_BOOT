COLD_BOOT

재생은 바꿀 수 없어. 하지만 보는 건 몇 번이고 할 수 있어.

누나의 PC에 남은 11월 20일 밤 두 시간이 계속 반복해서 재생됩니다. 자정이 되면 누군가 원격으로 PC를 지우고, 화면은 다시 22:00으로 돌아갑니다. 회차를 반복하면서 그날 밤 무슨 일이 있었는지 알아내는 타임 루프 수사 게임입니다.

BUFFER-600(실시간 관찰), LAST_LOGIN(PC 탐색)에 이은 세 번째 데스크톱 수사 게임입니다.

줄거리

2026년 11월 25일 새벽, 한도윤에게 누나 한서진이 예약해 둔 메일이 도착합니다.

이 메일이 도착했다면, 나는 사흘 동안 로그인하지 못한 거야.

첨부 파일은 COLD_BOOT_20261120.vmimg입니다. 서진이 직접 만든 기록 도구로, 매일 밤 22:00에 PC 스냅샷을 뜨고 그 뒤에 오간 통신과 파일 변경을 모두 저장합니다. 이미지를 켜면 그날 밤이 그대로 다시 재생됩니다.

플레이 방법
동작	방법
앱과 파일 열기	바탕화면 아이콘이나 파일을 더블클릭 (터치 화면은 한 번 탭)

처음으로 되감기	시작 메뉴 → 22:00으로 되감기
닫기	Esc
규칙
한 회차는 22:00부터 24:00까지입니다. 1배속 기준으로 약 4분이 걸립니다.
보는 순간에만 단서가 기록됩니다. 창이 열려 있고 최소화되지 않은 상태여야 합니다.
어떤 기록은 몇 분 뒤에 사라집니다. 그 시각에 그 창을 보고 있지 않았다면 다음 회차를 기다려야 합니다.
회차가 바뀌면 PC는 처음 상태로 돌아갑니다. 수사 노트에 적힌 단서는 남습니다. 수사 노트는 가상 PC 바깥(도윤의 노트북)에 있기 때문입니다.
작업 표시줄 위쪽 타임라인에 이미 알아낸 사건의 시각이 호박색으로 표시됩니다. 다음 회차 계획을 세울 때 쓰세요.
준비가 되면 수사 노트의 보고서 탭에서 세 질문에 답합니다. 몇 개가 맞았는지만 알려 줍니다.
가상 PC 안의 앱
링크톡: 하린, 가족, 개발팀과 나눈 대화가 그날 밤의 시각에 맞춰 도착합니다.
메일: 회사 공지와 보안 알림이 옵니다.
파일 탐색기: 문서, 다운로드, 사진, 휴지통, USB 드라이브를 볼 수 있습니다.
이벤트 뷰어: 시스템 로그가 실시간으로 쌓입니다.
메모장, 사진 뷰어, 압축 해제, CSV 뷰어: 파일을 열면 나타납니다.
실행

빌드 과정이 없습니다. index.html을 브라우저로 열면 됩니다.

bash
# 로컬 서버로 열고 싶다면
python3 -m http.server 8000
# → http://localhost:8000
1280×760 화면을 창 크기에 맞춰 확대·축소합니다. 데스크톱 브라우저를 권장합니다.
진행 상황(회차, 단서, 메모, 보고서 답)은 브라우저의 localStorage에 저장됩니다. 수사 노트 아래의 기록 전부 지우고 처음부터로 초기화할 수 있습니다.
글꼴은 Google Fonts(Noto Sans KR, JetBrains Mono)를 불러옵니다. 오프라인에서는 시스템 글꼴로 대신 표시됩니다.

사건은 모두 EVENTS 배열 한 곳에 있습니다. 시각(t)과 종류(msg, mail, log, file, typing, delete, usb, wipe)를 적으면 됩니다.

js
{ t: '23:41', type: 'msg', chat: 'harin', who: 'harin', key: 'slip', clue: 'deleted', text: '…' },
{ t: '23:43', type: 'delete', chat: 'harin', key: 'slip' },

clue를 붙이면 플레이어가 그 항목을 보는 순간 수사 노트에 기록됩니다. 단서 내용은 CLUES에 적습니다.

디자인 메모
분위기: 비 오는 금요일 밤, 오피스텔 창밖의 도시. 빗줄기와 바닥에 튀는 물방울은 캔버스로, 불 켜진 창문과 깜빡이는 항공 장애등은 SVG로 그렸습니다.
두 개의 세계: 가상 PC 안쪽은 차가운 남색과 파랑, PC 바깥(도윤의 수사 노트)은 따뜻한 호박색 종이로 구분했습니다.
긴장감: 23:30부터 하늘빛이 바뀌고, 23:52부터 화면이 간헐적으로 튀며, 23:55부터는 가장자리가 붉게 맥박칩니다. 23:58에는 원격 초기화 화면이 지워지는 파일 목록을 보여 줍니다.
사진 세 장(제천 할머니 집, 다락 비밀기지, 강릉 바다)은 SVG로 그렸고, 옛날 디지털카메라의 날짜 각인을 넣었습니다.
prefers-reduced-motion 설정을 따르면 움직임과 빗줄기가 줄어듭니다.
